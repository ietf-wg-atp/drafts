# ATP Working Drafts

This is the working area for the IETF [ATP Working Group](https://datatracker.ietf.org/wg/atp/about/) Internet-Drafts.

**NOTE**: _Substantive discussion in issues is strongly discouraged; please use the mailing list._

The Authenticated Transfer Protocol (ATP) working group is developing a set of Standards Track specifications that enable creation of decentralized global networks for publication of self-certifying data.

The work includes a repository format, a sync protocol, a URI scheme, and an interface for the account identifier system.
